# FolioTone support site

Static pages for the iOS app FolioTone: Read Docs Aloud (小学声 - 看文读文), served by GitHub Pages.

- `privacy.html` / `privacy-zh.html`: privacy policy (en / zh-Hans)
- `support.html` / `support-zh.html`: support and FAQ (en / zh-Hans)
- `licenses.html`: open-source acknowledgements with full license texts

Plain HTML and CSS: no scripts, external fonts, trackers or analytics.
